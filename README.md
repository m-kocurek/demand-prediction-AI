**Guidelines for the report:**

1. **Description of the problem and the data**  
General description of the domain the data relates to, number of records, names and number of input variables divided into qualitative and quantitative. Basic statistics (min, max, mean, standard deviation) and a histogram for the output variable. Clear statement of what problem is being solved (regression, classification, segmentation).

2. **Data preprocessing**  
Number of missing records and the method used to solve this problem, normalization/standardization of input data, transformations performed on the data (depending on the problem, e.g. for time series the average of the last 10 records, for image recognition processing with graphical filters). Method of splitting into training and test sets.

3. **Description of the neural networks used**  
Type and architecture of the network, number of training epochs, method of training the network. Information about own implementation / framework used. At least 2–3 different network architectures.

4. **Discussion of results and conclusions**  
Results of the networks collected in a table, divided into training and test sets. At least 2 metrics, together with a comment explaining why these particular ones were chosen and not others. Subjective assessment of whether the results are satisfactory, with justification. Conclusions and further proposals for the development of the project.
